# 라스트 테이크 · 영화 제작사 데모

정적인 카드와 월 단위 선택으로 진행하는 한국어 영화 제작사 경영 게임입니다.

## 실행

`dist/`를 정적 웹 서버의 공개 디렉터리로 지정합니다. `index.html`이 진입점이며 외부 API나 설치할 패키지는 없습니다. ES 모듈을 사용하므로 `file://` 대신 웹 서버로 실행합니다.

## 구현 범위

- 플레이어와 AI 제작사 9곳, 총 10개 회사
- 작가 200명, 감독 200명, 주연 남녀 각 200명, 조연 남녀 각 400명
- 재현 가능한 가상 인물 이름과 능력치, 전문 장르, 계약료, 독점 제작 일정
- 작가의 시놉시스 제안과 직접 의뢰, 원작 장르를 포함한 최대 3개 장르 조합
- 감독 1명, 주연 2명, 조연 4명 직접 또는 추천 캐스팅
- 독립영화 6개월, 상업영화 9개월, 블록버스터 12개월
- 제작사별 동시 제작 최대 3편, 개봉 간격 최소 2개월
- 서로 다른 제작 사건 4개, 전체 사건 40종 및 사건별 선택지 3개
- 완성작 1회 추가 제작: 12개월, 최초 제작비 40%, 품질 +8
- 개봉 전 가상 매체 3곳의 평론, 유사 장르 경쟁과 분기별 관심 장르
- 월별·누적 관객, 극장 매출, 제작사 정산, 작품 손익, 관객 감소 시 상영 종료
- 매년 12월 결산 후 작품상·감독상·각본상·주연상·흥행상
- 시작 자본 150억, 월 운영비 0.25억, 월 대출 이자 0.5%, 대출 및 상환
- 브라우저 localStorage 자동 저장. 기기·브라우저 간 동기화는 하지 않습니다.

## 구성

- `dist/data.js`: 인물 생성, 장르와 시놉시스, 제작 사건
- `dist/engine.js`: 상태 전이, 제작·개봉·흥행·재무·시상식 규칙
- `dist/app.js`: 카드 화면과 사용자 조작, 선택적 WebMCP 읽기·기획 진입 도구
- `dist/style.css`: 반응형 데스크톱·모바일 화면

## 0.2 · 영화인의 생애와 시리즈

- 매년 1월 나이 +1, 어린이 6~17세 / 성인 18~39세 / 중년 40~64세 / 노년 65세 이상
- 65세부터 은퇴 가능. 현재 계약은 완료하고 은퇴하며 신규 계약은 중단
- 고령·갑작스러운 별세는 짧은 알림으로 처리. 고인의 이력은 보존하고 같은 프로필 아이콘을 쓰는 새 인물이 6세부터 시작
- 작가와 감독의 어린이 세대는 18세부터 계약 가능. 배우는 어린이 배역으로 참여 가능
- 제작 중 별세 시 대체 인물을 자동 섭외하고 이전 참여 기록을 보존. 대체 인력이 없으면 섭외가 될 때까지 제작만 일시 대기
- 계약 당시 제작진 스냅샷으로 이미 제작한 영화의 능력치와 이름 기록을 보존
- 성향 및 함께한 작품 성적에 따른 궁합: 계약료와 예상 품질 반영, 낮은 궁합에도 의외의 성과 가능
- 성공·실패·단일 작품 천만 관객 경력, 계약료 배수와 품질 영향, 최고 흥행 기록
- 강점 밖 장르에서의 반전 성과, 좋은 궁합의 실패 가능성, 제한된 흥행 변동
- 상영 종료한 자사 영화에서 속편 생성. 별도 예산·사건·제작 기간과 원작 연결, 출연진 재섭외 또는 변경
- 기존 v1 저장의 회사·자금·작품을 유지하는 v2 변환

추가 검증: `node tests/career.mjs`


## 0.3 · 제작 계약과 홍보

- 결혼·열애설은 최신 요구대로 긍정/부정/중립 반응을 모두 지원하며 성인 가상 인물에게만 발생합니다. 미담/봉사는 관객 관심을 높입니다.
- 40종 중 작품당 네 번의 사건: 음주운전·폭행·확인된 범죄·과거 학교폭력 대응, 추가 개런티, 감독 교체, 배우 하차, 시나리오 수정 포함. 상세 범죄 묘사는 없습니다.
- 귀책 하차: 계약료 100% 반환 + 30% 위약금 수령. 제작사 교체: 25% 반환 + 25% 보상 지급. 대체 인물의 규모 반영 계약료 별도. 교체 품질 -3과 사건 선택 효과를 함께 기록합니다. 이는 게임 규칙입니다.
- 추가 개런티: 대상 계약료의 30%. 반환 및 위약금은 증가한 계약료를 기준으로 계산합니다. 이미 정산한 계약은 재정산하지 않습니다.
- 잡지/기자 인터뷰/유튜브/방송/굿즈 각 1회, 세 가지 상호작용. 홍보 없이 개봉 가능. 굿즈는 홍보용으로 판매 수익은 모델링하지 않습니다.
- 애니/만화/소설/게임 가상 원작 8편. 제작 확정 시 선급금, 극장 매출 50%인 제작사 몫에서 5~12% 원작료 차감. 속편도 선급금과 배분 조건 승계.
- 제작 75%부터 포스터 12종 선택. 미선택 개봉 시 장르 기본 포스터. 생성 일러스트를 재사용하고 영화별 제목을 표시합니다.
- 제작사 로고 8종. 인물 초상화는 남녀 각 4개 정체성 x 4단계 연령, 총 32개 이미지 셀을 1,600명에 재사용합니다. 환생은 같은 정체성의 어린이 이미지입니다.
- 인물 특성 8종: 연기파는 예상 품질, 아이돌 출신/홍보 소통형은 홍보 반응에 영향을 줍니다. 기존 능력치와 강점 장르도 계속 적용됩니다.
- 호감 궁합 78 이상, 촬영 중인 다른 작품 참여자 제외, 작품당 한 번 카메오 초청. 수락 여부는 궁합에 따른 결정, 출연료 0원. 수락 시 +2 품질/+3 인지도, 제작 기간 일정 예약 및 작품 히스토리 반영.
- v1/v2 저장은 현금과 작품을 유지한 채 v3으로 이전합니다. 기존 계약은 현시점 기준의 추정 계약 내역을 초기화합니다.

검증: `node tests/simulation.mjs`, `node tests/career.mjs`, `node tests/expansion.mjs`. 브라우저 기반 검증은 수행하지 않았습니다.


## 0.4 · 친밀도와 세부장르

- 잡지, 기자 인터뷰, 유튜브, 방송, 굿즈 기관을 각각 10곳씩 총 50곳 제공합니다. 모두 가상 기관이며 고유 이름/도달력/기본 가격이 있습니다.
- 기관↔인물, 기관↔제작사, 인물↔인물, 인물↔제작사 친밀도는 0~100. 0~19 매우 나쁨 / 20~39 나쁨 / 40~59 보통 / 60~79 좋음 / 80~100 매우 좋음으로 표시합니다.
- 각 관계는 월별 78% 유지, 22% 확률로 ±1~3 변화합니다. 저장 시드와 누적 변화를 사용해 재접속 또는 화면 열기로 재추첨되지 않습니다. 전체 관계를 매번 저장하지 않고 필요할 때 같은 결과를 계산합니다.
- 친밀도는 전문적 궁합과 독립된 값입니다. 제작사/동료 친밀도는 계약 배수에, 팀 친밀도는 예상 품질에, 기관과 제작사/출연진 관계는 홍보 비용과 인지도에 영향을 줍니다. 카메오는 이제 궁합 대신 친밀도를 기준으로 합니다.
- 계약/현장 선택/촬영 완료/하차 정산/홍보 협업/카메오 초청은 친밀도에 누적 반영됩니다. 새 세대 인물은 새 ID로 새로운 관계를 시작합니다.
- 인물 프로필에서 10개 제작사 및 50개 기관과의 관계를, 비교 검색에서 상대 인물과의 궁합 및 친밀도를 확인합니다. 기관 상세에는 제작사 관계 및 인물 검색이 있습니다.
- 13개 장르별 세부장르 3종, 총 39종. 선택한 장르마다 1개를 고르며 장르 변경 시 유효한 선택만 유지합니다. 세부장르 기본 +1, 다른 선택 장르와 조화 +2/충돌 -3, 총 효과 -8~+8 품질. 기획 화면에서 조화/충돌 장르와 결과를 미리 확인합니다.
- 기존 작품은 세부장르 미지정/효과 0으로 보존하고, 새 기획 및 AI 제작은 세부장르를 선택합니다. v1~v3 저장을 v4로 이전합니다.
- 추가 검증: `node tests/relationships.mjs` — 기관 수, 5단계, 궁합 독립성, 시간 변화/유지, 저장 재현, 계약 및 홍보 영향, 세부장르 유효성과 구버전 이전.


## 1.0.0 · 창고영화와 개봉 전략

- 홍보매체별 대표 이미지를 사용하며 기관 이름과 관계/견적은 각각 표시합니다. 대표 이미지의 매체별 재사용은 의도된 구성입니다.
- 분기마다 기간 한정 이벤트가 시작되며 대상 장르, 2~5개월의 적용 기간, 관객 15~35% 보너스를 표시합니다. 기존 분기 관심 장르의 개봉 첫 달 12% 보너스도 유지합니다. 기간 이벤트끼리는 최대치만 사용합니다.
- 매월 상영 성적에 적용한 이벤트 보너스를 기록합니다. 흥행 결과에는 작품·경쟁·홍보 등도 계속 영향을 줍니다.
- 제작 완료 후 창고로 보관하면 개봉 예정 경쟁에서 빠집니다. 저장·다음 달 진행으로 자동 개봉되지 않습니다. 창고에서 꺼내기 또는 직접 개봉이 가능하며, 제작사당 개봉 간격 규칙은 동일합니다.
- 크랭크업은 본 제작 일정의 80% 이상 진행 및 대기 사건 결정 후 기록합니다. 나머지 기간은 후반 작업입니다. 추가 제작은 10개월차 크랭크업, 12개월차 완료로 기록합니다.
- 게임 시간이 월 단위이므로 날짜도 연·월로 기록합니다. 구버전에는 세부 촬영 기록이 없으므로 추정 복원된 일정은 별도 표시합니다. 실제 개봉월은 바꾸지 않습니다.
- 추가 검증: `node tests/release.mjs` — 15개월 보관 후 개봉, 원래 기록 보존, 추가 제작 일정 분리, 흥행 이벤트 적용과 만료, 구버전 저장 이전.


## 1.0.1 · 휴대폰 세로 화면

좁은 화면(600px 이하) 또는 세로 화면(900px 이하)에서 카드 한 열, 전체 화면 대화창, 독립 본문 스크롤, 하단 결정 버튼, 안전 영역 여백을 적용합니다. 화면 방향을 강제로 잠그지 않습니다. CSS 및 모듈 참조를 점검했으며 실제 휴대폰/브라우저 시각 검증은 수행하지 않았습니다.


## 1.0.2 · 초상화 및 스크롤 수정

초상화는 실제 img 요소와 고정 크기 잘라보기로 표시하며 이미지 선로딩·실패 재요청을 지원합니다. 1,600명의 연령별 이미지 연결과 32개 원본 셀을 확인했습니다. 대화창은 기획 단계·배역·필터·페이지별 위치를 독립 저장하며 인물 선정 후 기존 캐스팅 위치로 돌아옵니다. `node tests/portraits-scroll.mjs` 통과. 실제 휴대폰 시각 검증은 수행하지 않았습니다.
